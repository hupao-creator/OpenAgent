# 状态过渡实验室

视觉方向：沿用 Bart Lab 的暖灰画布和灰绿色控件，让同一只 Bart 连续行动。
页面结构：左侧状态和序列，中间角色预览，右侧节奏与硬切对照。
交互方向：目光先行、部件之间接力、身体稍后跟随，中途切换保留当前姿态与速度。

入口为 `/transitions.html`，第二版整段动作默认 550ms，可调整 300–900ms。眼神在前段回应，部件随后交接，身体最后落定。支持正常／半速／四分之一速度、暂停、拖动底部进度线逐帧观察、重放上一次切换、完整序列、连续打断、同步初版插值对照。共享逻辑时钟驱动大预览、小预览和对照。隐藏页面暂停，减少动态效果时静态展示。

部件之间的关系：

- 运行与思考：三个 loading 点沿角色外侧迁往文字圆弧的三个节点，光点收小，三段文字从相同节点展开；反向时文字先聚成节点，再接回三个 loading 点。
- 思考与工具：文字沿圆弧收向同一个状态点，蓝点变绿，再由该点展开括号与工具名称。反向时标签收回，思考文字从共享节点展开。
- 工具与运行：标签折回绿色状态点，状态点沿外侧回到底部并拆成三点。
- 最终答复：已有装饰收回状态点，同一个点改变颜色和尺寸，变为未读标记；不重叠绘制第二个徽标。
- 眼神指向交接部件，轻微眯眼完成眼型变化，身体约晚 60ms 跟随。所有部件都保留过渡中的位置、揭示范围和速度，支持连续改向。

三个快捷演示用于比较光点／思考链、思考链／工具、工具／光点／答复；初版对照保留同时插值的方式。

复用生产角色轮廓、配色、眼型参数、运行光点轨迹、阅读眼动及身体轨迹。过渡模型和绘制器位于生产 `bart-motion/resident-*` 模块，由 Worker 和 Lab 共同使用；Lab 只提供控制面板、示例文案和初版对照。正式 Dock 使用真实思考文本、工具名和未读状态，保留原有展示队列、专用动作及答复导航。
