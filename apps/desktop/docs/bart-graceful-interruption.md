# Bart 导航的连续打断

Spec：[#268](https://github.com/xinyuan0801/OpenAgent/issues/268)。承接 #251 暂缓的打断需求，2026-09-16。

设置页飞行和穿眼镜头在方向改变时保留同一表面、角色、快照和舞台租约。从正在显示的位置减速、转向最新目标；返回途中也能再次反向。创建任务没有业务取消入口，本次不增加卡片收拢/撤销演出。对外通用 Motion API 仍未扩展。

## 时间轨道与所有权

准备好的几何路径不变，另设程序时间相对绝对单调时钟的映射。初次播放线性推进；接管时采样当前程序时间及其速度，用三次 Hermite 曲线接到目标端点、终速为零。反向起点保持位置与一阶速度，允许极短的惯性延续。采样限制在准备好的路径范围内；原路径在端点已缓入缓出。

接管时长随剩余路程变化，限制在 180–900 ms。连续反向采样上一条接管轨道，不采样最初动作，也不通过 DOM 端点重建角色位置。

Worker 的 `redirect` 接收前后运行身份与新轨道。旧完成、落地和释放不能改变新运行；所有纹理、借出角色和被覆盖 DOM 留在同一所有者下，直到最新目标落地。不会在接管时清空、resize、重新预热或借出角色。

跨页角色继续由 Worker 绘制在 256 CSS px 表面，位移通过同一绝对起点的合成器 transform 关键帧推进。主线程只在用户命令时提交一次轨道，不参与后续帧。穿眼镜头在 Worker 内对同一组页面快照反向采样。

正常设置开关的 scene-cut 带有来源，现有跨页飞行保留其所有权，其余冲突演出仍收到失效通知。镜头正常反向复用捕获和封口；观察器绑定场景身份，反向后依旧检查内容有效性。

设置页返回期间保留 Cmd/Ctrl+, 重新打开的入口，包括页面已经收拢、Bart 尚未落地的阶段。页面继续使用圆形裁切和透明度转场，去掉内容层的 4% 缩放，使两端落点在重复反向时保持稳定。起点和终点都提前准备引擎标记并校验完整屏幕矩阵；返航目标移动同样触发安全交接。

## 明确边界

普通反向不调用安全中止。页面卸载、几何/内容失效、减少动态效果、图形错误仍交接到当前真实页面；这些事件不能保证旧截图还能忠实代表新页面。打开另一任务/设置等改变页面内容的导航保留安全交接，不继续播放失效快照。

新意图须先由主线程收到并提交。接管已经发布到合成器后，即使 Renderer 主线程阻塞，Worker/合成器仍完成减速、反向及终态；主线程恢复后才交接真实 DOM。隐藏窗口、系统暂停、GPU 饱和不承诺物理零丢帧。

## 验证

- 数值测试：接管边界的位置、速度一致，80 次不同间隔的重复接管有界，端点保持静止。
- 运行测试：旧 release/landing/performed 不抢新运行，借出角色在返航终点交回原座位。
- React / App：Cmd+B、Cmd+K、Cmd+Shift+B，中途反向、旧完成、内容变化、焦点和卸载。
- 原生 Electron：同一 canvas 保持可见，飞行接管前后合成矩阵连续；从两个端点分别出发，一次/连续三次反向，接管后注入 2/5 秒同步 Renderer 阻塞，原生内容帧继续变化、主线程负对照冻结，最新页面交接后无残留纹理/锁。返航目标移动会使旧几何失效。
- 真实设置页：opening 中按返回，保留飞行直到 Dock 落地再结束页面生命周期；关闭 120/410 ms 后用真实快捷键重新打开，覆盖页面仍在收拢和已收拢的两种阶段。
- 原有 120 Hz 飞行节奏、卡片生成视觉、全场景 Worker 隔离套件继续纳入 verification。
